❓ Frequently Asked Questions
Werden Bilder an einen Server gesendet?

Nein. Die gesamte Komprimierung erfolgt direkt im Browser. Deine Dateien verlassen nie dein Gerät und werden nie auf einen Server hochgeladen.

Welche Formate werden unterstützt?

Der Komprimierer unterstützt JPG/JPEG, PNG und WebP. Alle Ergebnisse werden automatisch in JPEG umgewandelt.

Wie stark lässt sich komprimieren?

Die Komprimierung liegt je nach Bild und gewählter Qualität meist zwischen 40 % und 80 %. Hochwertige JPG-Originale lassen sich am besten komprimieren.

Beeinträchtigt die Komprimierung die Bildqualität?

Der Komprimierer nutzt ein verlustbehaftetes Verfahren, das die Dateigröße verringert und dabei eine akzeptable Bildqualität erhält. Je stärker die Komprimierung, desto etwas geringer die Qualität.

Bleibt die PNG-Transparenz erhalten?

Nein. Dieser Komprimierer wandelt PNG in JPEG um, und JPEG unterstützt keine Transparenz. Hat dein Bild einen transparenten Hintergrund, wird er automatisch durch einen weißen Hintergrundersetzt. Um PNG-Transparenz zu erhalten, nutze einen speziellen PNG-Komprimierer wie TinyPNG.

Welche Qualitätsstufe ist für die Komprimierung am besten?

80%–85% ist ideal zum Teilen online und per E-Mail – ausgezeichnetes Gleichgewicht zwischen Qualität und Größe. 60%–75% für eine stärkere Verkleinerung bei akzeptabler Qualität. 90%+ für den Druck. Der Standardwert von 80 % passt für die meisten Fälle.

Warum kann das komprimierte Bild größer sein als das Original?

Das passiert, wenn das Original schon gut komprimiert oder sehr klein ist. Auch große PNGs, die mit hoher Qualität in JPEG umgewandelt werden, können ähnlich groß bleiben. Lösung: Senke die Qualität schrittweise, bis die gewünschte Ersparnis erreicht ist.

Lassen sich WebP-Bilder komprimieren?

Ja. WebP-Bilder können hochgeladen und komprimiert werden. Das Ergebnis wird automatisch in JPEG umgewandelt. Wenn du das WebP-Format behalten willst, nutze ein spezielles Tool.

Bildkomprimierer — Größe verringern ohne Qualitätsverlust

Dieses Tool komprimiert Bilder direkt in deinem Browser mit der HTML5-Canvas-API. Es werden keine Dateien auf einen Server hochgeladen – deine Fotos bleiben vollständig privat. Unterstützt JPEG, PNG und WebP. Ziehe dein Bild hinein, wähle eine Qualitätsstufe und lade das Ergebnis sofort herunter.

Die richtige Qualitätsstufe wählen

Qualitätsstufen von 70–85 % bieten das beste Gleichgewicht – meist 60–80 % kleinere Dateien bei kaum sichtbarem Qualitätsverlust. Unter 60 % können sichtbare Artefakte auftreten. Über 90 % wird die Verkleinerung minimal. Für Profilbilder und Blogbilder sind 75–80 % ein guter Ausgangspunkt.

Warum die Bildgröße für SEO und Ladezeit wichtig ist

Ein 4-MB-Foto zwingt jeden Besucher, 4 MB herunterzuladen, nur um deine Seite zu sehen. Auf 400 KB bei ähnlicher Bildqualität komprimiert, lädt die Seite 10-mal schneller. Googles Core Web Vitals (LCP) messen direkt, wie schnell dein größtes Bild lädt – kleinere Bilder verbessern sowohl die Nutzererfahrung als auch das Suchmaschinenranking.
