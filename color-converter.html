❓ Frequently Asked Questions
What is a HEX color code?

A HEX color code is a 6-digit hexadecimal number (like #3B82F6) representing a color's red, green and blue components as two hex digits each (00 to FF, i.e. 0 to 255). It's the most common way to specify colors in web design (CSS, HTML).

What does RGB stand for?

RGB stands for Red, Green, Blue — the three color channels that combine (by adding light) to create any color on a screen. Each channel ranges from 0 to 255, so RGB(0,0,0) is black and RGB(255,255,255) is white.

What is HSL and why use it?

HSL stands for Hue (0-360°, the color itself), Saturation (0-100%, how vivid) and Lightness (0-100%, how light or dark). Unlike RGB, HSL maps closely to how humans intuitively describe color, making it easier to create shades and tints of the same hue by just adjusting the Lightness value.

How do I convert HEX to RGB?

Split the 6-digit hex code into three 2-digit pairs (RR, GG, BB) and convert each pair from base-16 to base-10. For example #FF5733 splits into FF (255), 57 (87), 33 (51), giving RGB(255, 87, 51).

What is a hex color's alpha channel?

An 8-digit hex code (like #3B82F6CC) adds a 4th pair representing alpha (opacity), from 00 (fully transparent) to FF (fully opaque). This is sometimes called HEX8 or RGBA hex notation.

Three Ways to Describe the Same Color

HEX, RGB and HSL are three different notations for the exact same underlying color information — a screen pixel's red, green and blue light intensities. HEX packs them into a compact 6-character code that's easy to paste into CSS. RGB spells the same three numbers out in base 10, which is friendlier for reading and generating programmatically. HSL re-parameterizes color around how people actually think about it — "a bright blue" (hue + high saturation) that's "a bit darker" (lower lightness) — which is why design tools often expose HSL sliders even though the color is stored as RGB underneath.
