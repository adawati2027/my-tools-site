❓ Questions fréquentes
Le QR code est-il adapté à l'impression ?

Oui — l'image générée fait 220×220 pixels, ce qui convient aux écrans et aux petites impressions. Pour une grande affiche, des outils SVG sont recommandés pour une meilleure qualité.

Faut-il Internet pour scanner un QR code ?

Scanner le code avec l'appareil photo ne nécessite pas Internet. Mais si le code contient un lien web, il faudra une connexion pour l'ouvrir.

Combien d'informations un QR code peut-il contenir ?

Au maximum environ 4 296 caractères alphanumériques. Moins il y a de texte, plus le code est net et facile à scanner — les liens courts sont recommandés.

Un QR code peut-il expirer ?

Un QR code statique n'expire jamais. Mais s'il renvoie vers une URL qui expire ou change, le lien cessera de fonctionner. Le code lui-même reste valable indéfiniment.

Comment associer un QR code à une carte de visite ?

Créez un QR code avec le lien de votre page LinkedIn, de votre site ou votre numéro WhatsApp au format wa.me/+9685XXXXXXX, puis enregistrez-le et imprimez-le sur votre carte de visite.

Quelle est la différence entre un QR code et un code-barres ?

Un code-barres est unidimensionnel et ne contient qu'environ 20 chiffres. Un QR code est bidimensionnel et peut contenir des milliers de caractères. Les QR codes se scannent plus vite et fonctionnent même partiellement endommagés.

Puis-je ajouter un logo dans un QR code ?

Cet outil génère des codes sans logo. Pour en ajouter un, essayez QR Code Monkey ou Canva — mais un logo masque une partie du code et peut réduire la fiabilité du scan.

Quelle est la meilleure taille pour imprimer un QR code ?

Le minimum pour une impression nette est de 2×2 cm. Pour les affiches et autocollants, 3 à 5 cm sont recommandés afin d'assurer un scan facile avec tous les types d'appareils photo.

Générateur de QR code — usages et bonnes pratiques

Un QR code (Quick Response) est un code-barres 2D que les smartphones peuvent scanner avec leur appareil photo. Il peut contenir une URL, du texte, une adresse e-mail, un numéro de téléphone ou des identifiants Wi-Fi. Ce générateur crée les QR codes entièrement dans votre navigateur — aucun envoi, aucun compte requis.

Usages les plus courants

  • Menus de restaurant et commande sans contact
  • Partage du mot de passe Wi-Fi avec les invités
  • Relier des supports imprimés (cartes de visite, flyers) à un site web
  • Billets d'événements et cartes d'embarquement numériques

Taille du QR code et distance de scan

Pour l'impression, un QR code doit mesurer au moins 2 cm × 2 cm. La distance de scan est d'environ 10 fois la taille du code — un code de 3 cm se scanne à 30 cm. Des URL plus courtes produisent des codes plus simples qui se scannent plus vite et plus sûrement.
