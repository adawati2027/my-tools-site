Random Number Generator

Generate random numbers for raffles and games
❓ Preguntas frecuentes
¿Cómo genera el generador los números aleatorios?

El generador usa la API Web Crypto integrada en el navegador (crypto.getRandomValues), diseñada para datos aleatorios criptográficamente seguros y más fiable que las funciones matemáticas tradicionales.

¿Sirve para sorteos y concursos oficiales?

Sí: el generador usa un algoritmo criptográfico adecuado para sorteos justos. Para sorteos con validez legal o institucional, consulta a la autoridad competente por si hay requisitos adicionales.

¿Cuántos números se pueden generar a la vez?

Hasta 20 números por operación. Usa el control deslizante para fijar el mínimo, el máximo y la cantidad deseada.

¿Se guardan los números generados?

El generador conserva solo los últimos 10 resultados en la sesión actual del navegador; no se guarda ningún dato en servidores ni fuera del navegador.

¿Qué rango de números admite?

Admite cualquier rango de números enteros. El mínimo debe ser menor que el máximo. Se pueden generar hasta 20 números por clic.

Generador de números aleatorios — usos habituales

Este generador usa la función integrada del navegador crypto.getRandomValues() (API Web Crypto), una fuente de aleatoriedad criptográficamente robusta adecuada para sorteos, juegos y muestreos. Los números se generan por completo en tu navegador: no se envía nada a ningún servidor.

Usos prácticos

  • Elegir ganadores de sorteos y concursos
  • Elegir al azar a un alumno en clase
  • Sustituir los dados en juegos de mesa
  • Seleccionar muestras aleatorias para encuestas
  • Asignar grupos en pruebas A/B

¿Es realmente aleatorio?

Usa la fuente de aleatoriedad criptográficamente segura del navegador (API Web Crypto), el mismo tipo de aleatoriedad que se usa con fines de seguridad, así que es muy adecuado para sorteos, juegos y extracciones justas. En sorteos con validez legal o institucional, cumple además los requisitos de la autoridad competente.
