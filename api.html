Adawati Public API

Gold spot price and USD exchange rates as free JSON

Two read-only GET endpoints return JSON. They are free to use. Responses include a source and a timestamp so you can show where the data came from.

Endpoints

  • GET /api/v1/gold?currency=OMR — 24-karat gold price per gram in the requested currency. currency is optional (default USD) and must be a 3-letter ISO code.
  • GET /api/v1/rates — USD-based exchange rates for all supported currencies.

Example: gold in OMR

{
  "metal": "gold",
  "karat": 24,
  "unit": "gram",
  "type": "spot",
  "currency": "OMR",
  "price": 0.00,
  "usd_per_troy_oz": 0.00,
  "rate": 0.000,
  "fetched_at": "2026-10-26T12:00:00.000Z",
  "source": "goldprice.dev (XAU/USD spot) + Exchange Rate API (open.er-api.com)",
  "note": "International spot price converted to the requested currency. Not a local market price."
}

The numbers above are placeholders. Live responses contain current values.

Example: exchange rates

{
  "base": "USD",
  "updated": "Sun, 26 Oct 2026 00:00:01 +0000",
  "source": "Exchange Rate API (open.er-api.com)",
  "provider_url": "https://www.exchangerate-api.com",
  "rates": { "USD": 1, "EUR": 0.00, "OMR": 0.000, "INR": 0.00 }
}

Gold response fields

  • price — gold price per gram in currency, rounded to 2 decimals.
  • usd_per_troy_oz — the USD spot price per troy ounce before conversion.
  • rate — USD to currency exchange rate used.
  • fetched_at — time the values were fetched (ISO 8601, UTC).

Errors

Errors return JSON with an error field.

  • 400 invalid_currency — currency is not a 3-letter code.
  • 400 unsupported_currency — the code is well formed but no rate is available for it.
  • 405 method_not_allowed — only GET is supported.
  • 502 upstream_failed — the data sources could not be reached. Try again later.

Caching and limits

  • Gold responses: cached up to 60 seconds.
  • Exchange rate responses: cached up to 1 hour.
  • CORS is open (Access-Control-Allow-Origin: *), so browser code on any site can call the API.
  • Rate limit: about 10 requests per 10 seconds per IP address. Going over the limit blocks further requests for a short time.

Sources and accuracy

Gold: goldprice.dev (XAU/USD spot). Exchange rates: Exchange Rate API via open.er-api.com. The gold figure is an international spot price converted to your currency. It is not a price from a local shop or dealer, and it does not include taxes or dealer margins.

The API is provided as is, without a guarantee of uptime or accuracy. Do not use it as the only basis for financial decisions.

Using the data

Please keep the source attribution in the responses when you display the data. Cache results on your side rather than calling the API on every page view.

❓ Frequently Asked Questions
Is the API free?

Yes. Both endpoints are free to call with GET requests and return JSON. Requests are rate limited per IP address.

Is the gold price a local market price?

No. The gold price is the international XAU/USD spot price converted to the requested currency at the current exchange rate. Local dealers add their own prices and margins.

How often is the data updated?

Gold responses are cached for up to 60 seconds. Exchange rate responses are cached for up to 1 hour. Check the fetched_at and updated fields in each response.
