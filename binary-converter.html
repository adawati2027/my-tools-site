❓ Frequently Asked Questions
What is binary?

Binary is base-2: every number is written using only the digits 0 and 1. Each position represents a power of 2 (1, 2, 4, 8, 16...), the same way each position in decimal represents a power of 10. Computers use binary because a transistor is naturally a two-state (on/off) switch.

How do I convert hex to binary?

Each hexadecimal digit maps to exactly 4 binary digits (bits), since 16 = 2⁴. For example hex A = binary 1010, hex F = binary 1111. To convert a full hex number, convert each digit separately and join the results: hex 2F = 0010 1111.

Why does hexadecimal use letters A–F?

Hex is base-16, so it needs 16 distinct digits. After 0-9 run out, the letters A through F are used to represent the values 10 through 15 in a single character.

What is octal used for?

Octal (base-8) was common in early computing because 3 bits map to exactly one octal digit (8 = 2³), making it a compact way to write binary. It's less common today than hex, but still appears in Unix file permission notation (e.g. chmod 755).

How many values can 8 bits (1 byte) represent?

8 bits can represent 2⁸ = 256 distinct values, typically counted from 0 to 255 (unsigned) or -128 to 127 (signed, using two's complement).

What is two's complement?

Two's complement is how computers represent negative numbers in binary. To negate a number, you flip every bit and add 1. It lets addition and subtraction use the same circuitry, and only 1 value (all zeros) represents zero, unlike sign-magnitude representation.

Number Base Conversion Explained

Every number system works the same way: each digit position represents a power of the base. Decimal (base 10) is what people use day to day because we have 10 fingers. Computers work natively in binary (base 2) because digital circuits are built from two-state switches — on or off, 1 or 0. Hexadecimal (base 16) and octal (base 8) exist as human-friendly shorthand for binary, because their bases are exact powers of 2, so each hex or octal digit maps cleanly onto a fixed number of bits with no remainder.

Where each base shows up in practice

  • Binary: the actual representation inside computer memory and processors — every value, from a number to a character to a pixel color, is ultimately stored as bits.
  • Hexadecimal: memory addresses, color codes (#FF5733), MAC addresses, hash digests (MD5, SHA), and byte-level debugging — because 2 hex digits = exactly 1 byte (8 bits).
  • Octal: Unix/Linux file permissions (e.g. 755, 644), and some older systems and protocols.
  • Decimal: everything meant for humans to read directly — prices, quantities, dates.

Worked example: converting 156

Decimal 156 breaks down as 128+16+8+4 = 156, using powers of 2 (128, 64, 32, 16, 8, 4, 2, 1) — so in binary that's 10011100. In hex, 156 = 9×16 + 12, so it's 9C (where C = 12). In octal, 156 = 2×64 + 3×8 + 4, so it's 234. Type 156 into the decimal field above to see this confirmed instantly.
