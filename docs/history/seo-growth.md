## Cross-site smart search, built 2026-09-10

The gap flagged in the QA-report pass above (`filterTools()` on `index.html` could only match cards already in its own DOM — a query like "jordan university" could never surface Jordan-specific tools since those live on a different page entirely) is now closed with a real, if v1-scoped, cross-site search index.

**`build-search-index.js`** (new script, run alongside `build-sitemap.js`): reads `sitemap.xml` (not the URL-source arrays directly — reusing the already-generated canonical URL list avoids duplicating `build-sitemap.js`'s own enumeration logic), maps each `<loc>` back to a local file path, and reads that file's `<title>`/`<h1>`/meta description/meta keywords to build a lightweight per-page record `{u: url, t: cleanTitle, s: lowercased searchable text}`. Excludes `ar/`/`fr/`/`es/`/`de/`/`ru/` (non-English lang variants — the homepage search is English-context) and `jo/games/` (quiz/trivia pages dilute tool-search relevance). Output: `search-index.json` at repo root, 90 entries, ~47KB.

**Real gap found and patched while building this**: several pages are simply missing an obvious English search term in their own on-page metadata — e.g. `omr-to-inr.html` never says the word "currency" anywhere (only "exchange rate"/OMR/INR/Rial/Rupee), and `jo/calculators/university-gpa/index.html` never says "university" in English (only "GPA" in its keywords, everything else is Arabic).
