❓ Frequently Asked Questions
What is ASCII?

ASCII (American Standard Code for Information Interchange) is a character-encoding standard that assigns a number from 0 to 127 to each English letter, digit, punctuation mark and common control character, so text can be stored and transmitted as numbers.

What is the ASCII code for the letter A?

Uppercase A is ASCII 65. Lowercase a is 97 (uppercase and lowercase letters are always 32 apart in ASCII). The digit character '0' is 48, and a space is 32.

What is the difference between ASCII and Unicode?

ASCII only covers 128 characters — enough for basic unaccented English text. Unicode is a much larger standard covering virtually every writing system in the world (Arabic, Chinese, emoji, etc.), and its first 128 code points are identical to ASCII for backward compatibility. UTF-8, the most common Unicode encoding on the web, encodes those first 128 characters as a single byte, exactly like ASCII.

How do I convert text to binary?

Each character is first converted to its ASCII/Unicode decimal code, then that number is converted to binary, usually padded to 8 bits (1 byte). For example 'A' = 65 = binary 01000001.

Why do some ASCII codes not print anything?

Codes 0-31 (and 127) are control characters, not visible symbols — they include things like Tab (9), Line Feed (10), and Carriage Return (13), originally designed to control teletype/printer behavior rather than to be displayed.

How Text Becomes Numbers

Computers only store numbers — every character of text is really just a number that a program agrees to interpret as a letter, digit or symbol. ASCII was the original standard for this mapping (published 1963), covering the 128 characters common in American English typewriters and teleprinters of the era. Because 128 = 2⁷, a full ASCII character fits in 7 bits, though it's almost always stored in a full 8-bit byte in practice, with the extra bit historically used for parity-checking or extended character sets.

A quick worked example

The word "Hi" is stored as two bytes: 'H' is ASCII 72 (hex 48, binary 01001000) and 'i' is ASCII 105 (hex 69, binary 01101001). Type "Hi" into the box above to see this generated live — this is exactly what happens, byte by byte, whenever text is saved to a file or sent over a network.
